# Personal Expense Tracker

A desktop expense tracking application built with Python and Tkinter.

## Features

- Add expenses with descriptions, amounts, and categories
- View transactions in a scrollable table
- Filter expenses by category
- Calculate total spending and transaction counts
- Delete expenses with confirmation
- Automatically save and load expenses using JSON
- Dark-themed graphical user interface

## Technologies

- Python
- Tkinter / ttk
- JSON
- UUID

## Getting Started

1. Clone the repository.
2. Make sure Python and Tkinter are installed.
3. Run the application:

```bash
python main.py
```

The application automatically creates `expenses.json` when you add your first expense.
